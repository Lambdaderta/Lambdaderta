## Projects

### [T-Lab RecSys](https://github.com/Lambdaderta/tlab_recsys) · Ongoing research

Two studies on music recommendation with Yambda-50M: retrieval and reranking with ALS, CatBoost, OpenFE-style feature generation, and LightGCN; and sequential recommendation with GPT-2/SASRec and offline RL. The combined reranker reached NDCG@10 of 0.0873 versus 0.0755 for CatBoost with manual features in a 2K-user study. The RL experiments explore AWR, off-policy REINFORCE, reward modeling, and SNIPS evaluation, with temporal splits and bootstrap comparisons. Reports include limitations and negative results, not just the best scores.

`Python` `PyTorch` `CatBoost` `ALS` `LightGCN` `SASRec` `Offline RL` `Recommender Systems`

### [TeamWeave](https://github.com/Anton15K/IBM_HACK) · IBM Bob 2.0 Hackathon

Co-developed TeamWeave for the lablab.ai IBM Bob 2.0 Hackathon. It turns coding tasks into dependency graphs: agents work in Git-bound workspaces, pass results to downstream tasks, and pause for human review. The platform integrates IBM Bob Shell and OpenAI-compatible models, with bounded tool calling, execution history, workspace change tracking, and cross-team handoffs.

Team project hosted in a teammate's repository. [Project overview](https://anton15k.github.io/IBM_HACK/).

`TypeScript` `React` `Fastify` `SQLite` `AI agents` `Tool calling` `IBM Bob` `Git`

### [AIO Robot](https://github.com/Lambdaderta/aio_robot)

A local AI agent that can use tools to control a robotic arm. I implemented the function-calling loop, structured tool outputs, argument validation, motion limits, and an MCP server. The system also includes a web interface, Telegram bot, speech input/output, and computer vision for mapping human poses to robot movements.

`Python` `FastAPI` `LLM agents` `MCP` `MediaPipe` `Arduino` `React`

### [Local Search](https://github.com/Lambdaderta/local_search)

An Android gallery with on-device semantic photo search in English and Russian. It indexes images locally with ruCLIP and ONNX Runtime, stores compact embeddings in SQLite, and searches without an account, server, or internet permission.

`Java` `Android` `ONNX Runtime` `Computer Vision` `SQLite` `Semantic Search`
